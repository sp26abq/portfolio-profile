Project Details: Campus Activity Web Hub

Holding Page Artifact

1. Problem Definition & Goals

University students often find sports schedules, club timings, and facility availability fragmented across disparate portals. The goal of this web application was to consolidate activity scheduling into an accessible, responsive single-point interface.

2. Architecture & Design Choices

The application was constructed using custom vanilla HTML, CSS, and modern JavaScript without framework overhead. This architectural decision ensured full control over document semantics, avoided bloated client-side bundles, and guaranteed strict conformance with WCAG 2.1 AA benchmarks.

3. Accessibility & Usability Highlights

The interface guarantees complete keyboard navigability via clear focus rings, passes all contrast thresholds (exceeding 7.5:1), and includes live ARIA regions to inform screen readers of dynamic content updates.
