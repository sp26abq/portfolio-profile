Technical Interests

Universal Accessibility & Inclusive Design

My interest in accessibility focuses on designing digital interfaces that provide equal access to users with visual, auditory, cognitive, and physical impairments. I focus on standard semantic HTML elements, ARIA design patterns, clear color contrasts, and fully tested keyboard navigation paradigms.

I aim to build applications where accessibility is a foundation of the architectural workflow rather than an afterthought, ensuring seamless experiences across screen readers and keyboard-only environments.

Distributed Web Architectures & REST APIs

I am interested in back-end infrastructure, distributed systems, and modern API architecture. Building clean REST interfaces with clear separation of concerns, transactional integrity, and normalized database schemas forms a primary part of my project work.

During my upcoming industrial placement, I aim to expand on this interest by contributing to high-throughput cloud back-ends and exploring containerized deployment pipelines.

Project Details: Campus Activity Web Hub

(Project Holding Page Artifact)

1. Overview & Problem Definition

Students regularly struggle to discover on-campus sports, community sessions, and wellbeing activities due to scattered information. This project established a unified, accessible web portal designed to make finding and signing up for events fast and straightforward.

2. Architecture & Approach

The solution was developed without external UI frameworks to ensure complete control over semantic document structure and keep page weight low. Styling uses custom CSS variables for easy theme customization, while client-side interaction is handled through vanilla JavaScript event listeners.
