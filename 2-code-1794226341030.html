Technical Interests

Universal Accessibility & Standards-Driven Frontend

My interest centers on creating digital software that delivers parity of experience to users relying on assistive technology, screen readers, and adaptive input controls. I specialize in semantic HTML structures, standard WAI-ARIA states, and high-contrast color systems.

I aim to apply accessibility directly into continuous integration workflows, ensuring user interfaces meet WCAG 2.1 AA specifications from day one of development.

I am keenly interested in transactional persistence and back-end service communication. Designing normalized database schemas, building transactional safety, and crafting performant SQL queries form a key foundation of my coursework.

During my placement, I intend to deepen my knowledge of scalable REST service patterns, database indexing optimization, and secure API data validation pipelines.
